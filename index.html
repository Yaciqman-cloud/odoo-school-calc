Comment intégrer ce calculateur dans Odoo

Méthode 1 : Intégration via le Module Website d'Odoo

Vous pouvez intégrer ce fichier dans n'importe quel élément Web d'Odoo.

  1. Allez dans le module Site Web (Website) d'Odoo.
  2. Créez ou éditez une page (ex: /calculateur-notes).
  3. Faites glisser un bloc de construction personnalisé ou un composant Structure > Snippet HTML / Code Embed.
  4. Copiez l'intégralité du code source de cette page HTML et collez-le directement.
