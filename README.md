# OdooSchool Calc & Convert

**Calculateur de Moyennes Scolaires & Convertisseur de notes** — prêt pour intégration Odoo.

## Fonctionnalités

- Calcul de moyennes par matière (coefficients + barèmes personnalisés)
- Moyenne générale pondérée + mentions (TB, B, AB, Passable…)
- Convertisseur de notes (sur 20 ↔ barème perso, lettre US, GPA)
- Simulateur d’impact d’une future note
- Import / Export JSON
- Mode sombre
- Stockage local (localStorage)

## Démo / Utilisation

Ouvre simplement le fichier `index.html` dans un navigateur, ou active **GitHub Pages** sur ce dépôt (Settings → Pages → Source = main / root).

Une fois GitHub Pages activé, le site sera accessible à :  
`https://yaciqman-cloud.github.io/odoo-school-calc/`

## Intégration Odoo

Voir le bouton **« Intégration Odoo »** dans l’application (module Website → Snippet HTML).
